# Legacy expanding-liquidity-window outputs

These artifacts are preserved, non-primary Phase 2–7 outputs generated before
the 2026-09-11 liquidity-universe correction. The implementation used the
median of all observations before each monthly rebalance and required only a
minimum of 20 observations. It did **not** use exactly the 20 immediately
preceding shared market dates.

Do not use these files as the project's primary results. Their file-level
integrity is recorded in `SHA256SUMS.txt`.
